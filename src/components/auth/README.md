# CrowMesh 登录 / 注册与独立眼球交互

运行 `npm run dev`，访问 `/login`、`/register`；当前预览为 http://localhost:3000/login。
表单只做本地校验，无登录、注册或重置接口，也不保存账号密码。

## 当前素材与分层

新来源：`乌鸦登录动画.mp4`，720 × 1280，约 2.65 秒。

- `public/media/crow-light-blended.mp4`：裁切到 720 × 950，去除右下角可灵水印；离线修补原眼球和闭合眼睑，保留电视光线。
- `public/media/crow-light-blended-poster.jpg`：同画幅、修补后的静态兜底。
- `PointerVideo.tsx`：在视频上叠加两只 SVG 眼睛，眼白固定，瞳孔独立跟随鼠标。
- 视频以 24 fps 正放后倒放形成 5.17 秒循环，不在首尾跳切颜色。
- 原版本 `crow-scrub.mp4` 和 `crow-poster.jpg` 留存但当前页面不再引用。

这次需求已从“鼠标 seek 整段视频”改为“光线持续播放 + 眼睛独立跟随”。
单个 MP4 的时间轴不能同时让光线播放、让眼睛停止，因此当前组件不再用指针 seek 视频。
浏览器原生解码光线循环；只对 SVG 瞳孔执行短时 rAF 插值，避免双重视频解码和频繁 seek。

## 密码输入时闭眼

登录密码、注册密码及确认密码获得焦点时闭眼，输入期间持续保持；点击其他区域或 Tab 离开后睁眼。注册的两个密码框之间切换时保持闭眼。通过字段名识别，不受显示/隐藏密码按钮改变 input type 影响。闭眼只切换 SVG 眼睛层，不暂停电视光线；睁眼后恢复当前指针方向。

## 输入和渲染

- `window` 捕获阶段的 Pointer Events 监听整个网页内容区，包括表单和页面空白；不局限于视频。
- 根据鼠标相对于眼睛的位置计算二维视线方向，并将瞳孔约束在眼白内部。
- rAF 按时间校正 lerp，60 Hz 时系数 0.15；指针事件只更新目标，不触发 React render。
- 移动停止后，缓动收敛到最后目标即取消 rAF；不会自动回正、眨眼或随机移动。
- 视频仍然继续循环。用户启用系统“减少动态效果”时停播背景，眼球直接响应输入。
- 视频和 SVG 共用同一个 cover 舞台，ResizeObserver 保证桌面、窄屏裁切位置一致。
- 手机支持触摸拖动；仅视频区域使用 `touch-action: none` 和指针捕获，表单仍能正常点击、选字和滚动。
- 聚焦动画区域后方向键可调整视线，Home 回正；不影响表单中的方向键。

## 生命周期和兜底

IntersectionObserver 判断动画区域是否在视口内，离屏时解绑全页指针和窗口监听，取消 rAF 并暂停视频；重新进入恢复。
标签页隐藏也暂停。卸载时清理所有事件、rAF、IntersectionObserver、ResizeObserver、媒体偏好监听并暂停视频。
metadata 可用且 duration 有限时预 seek 到 0.02 秒；首帧解码前或视频错误时显示海报，独立眼球仍可交互。
若浏览器拒绝静音自动播放，首次 pointerdown 会重试。网页无法监听浏览器地址栏、标签栏或其他程序的鼠标。

## 可复现的素材生成

`scripts/prepare-crow-animation.py` 包含裁切、眼区羽毛颜色修补和往返循环生成。
依赖 `imageio-ffmpeg`、`numpy`、`opencv-python-headless` 仅用于构建素材，网页运行时无需这些工具。

```sh
python scripts/prepare-crow-animation.py /path/to/乌鸦登录动画.mp4
```

眼睛坐标及修补范围针对当前素材；替换不同构图的视频需重新校准。
当前未使用 oil-motion skill 或动画库。

## 检查

TypeScript、受影响组件 ESLint、生产构建，以及浏览器中的首帧、持续播放、表单区域指针跟随、静止眼球和响应式舞台对齐。
移动端真机与 iOS 自动播放策略仍需真机验收。

## 眼区融合与闭眼细节

眼区遮罩和羽毛采样位置固定，完整覆盖原视频眼球与眼睑；不根据每帧颜色重新切换遮挡范围。使用周围干净羽毛估计空间二次曲面，让左侧受光和右侧阴影在眼区连续过渡；系数经 5 帧平滑去除噪声，避免此前统一 RGB 偏移产生的色块。遮罩边缘采用 smoothstep 柔化，鸟嘴轮廓保持原视频内容。

素材生成时验证每帧眼睛核心区域只含平滑羽毛光色，编码前误差低于 1.01/255，防止原眼睑漏出。生成使用新的素材文件名，避免旧缓存。

闭眼 SVG 使用半透明上眼睑阴影、细褶皱、渐细的闭合线、眼角与下缘微光，透出底层电视光色；睁眼增加细眼缘和小瞳孔反光。焦点、全页鼠标跟随和视频生命周期逻辑不变。
